# Jogo da Bolha Dev

RPG de ação 3D em terceira pessoa. Luz, sombra, água e céu em tempo real. Sem login.

Objetivo: visite o acampamento, derrote o goblin **HELIO** (capanga) e destrua o **REAL OFICIAL**.

## Heróis jogáveis

| Herói | Habilidades (`1` `2` `3`) |
| --- | --- |
| **Nicolas** (Conty) | Post viral no X · Networking · Lembrar do começo |
| **Matheus** (FitFolio) | Treino · Dieta · Reel que viraliza |

## Inimigos (5)

Pedro (CEO) · Elon Musk · ManoDeyvin · **HELIO** (goblin, mini-boss) · **REAL OFICIAL** (boss)

## NPCs no acampamento (`E`)

- **Sergio Banhos** — cookies (`C` para comer) e currículo (+XP)
- **Almeida** — upgrade de arma por moedas
- **Anderson** — hotfix (cura total + recarga das skills)

## Controles

`WASD` mover · mouse olhar · clique atacar · `1` `2` `3` habilidades · `E` falar · `C` cookie · `Espaço` pular · `Shift` correr · `ESC` pausar

Qualidade Alta/Média no menu de pausa.

```bash
npm install
npm run dev
```
